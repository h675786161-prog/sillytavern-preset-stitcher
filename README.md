# 玲·通用预设缝合机

面向 SillyTavern 的通用预设组件缝合工具。以 B 主预设为成品母版，从一个或多个 A 供体预设中选择提示词、正则、酒馆助手脚本或扩展块，自动适配 B 的结构并导出新预设。

## 下载

[玲·通用预设缝合机-v2.3.0.json](./玲·通用预设缝合机-v2.3.0.json)

## v2.3.0

- B 主预设与 A 供体均可直接读取酒馆中的聊天补全预设。
- 支持刷新列表、标记当前预设，以及依次加入多个供体。
- 防止同一个酒馆预设同时作为主预设和供体，也会拦截重复供体。
- 每个供体来源都可以单独移除，亦可一键清空。
- 保留本地 JSON 与 `.stitchpack.json` 文件入口。
- 只读取预设副本，不切换、保存、删除或覆盖酒馆当前预设。

## 安装

1. 下载上方 JSON 文件。
2. 在酒馆助手的「全局脚本」中导入。
3. 启用脚本，通过悬浮猫猫按钮或脚本按钮打开缝合机。

## 使用

1. 点击「刷新列表」读取酒馆聊天补全预设。
2. 选择并载入 B 主预设。
3. 选择一个或多个 A 供体预设，也可以改用本地文件。
4. 按页签勾选需要缝入的预设条目、正则、脚本或扩展块。
5. 调整冲突与安全设置，执行缝合并下载新的 B 成品。

## 安全说明

- 主预设和供体原对象不会被改写。
- 脚本 `data` 默认剥离，避免把 API Key、聊天记忆或私人设置带入成品。
- 「真正语义缝合」使用当前酒馆模型进行独立分析，不携带聊天记录、角色卡或世界书。
- 语义分析只发送 B 的协议摘要与已勾选组件，不发送脚本 `data`。

## 文件名

Git 和 GitHub 支持中文文件名。本项目保留中文成品名；仓库名使用英文，仅为提升网址、命令行与第三方下载工具的兼容性。
